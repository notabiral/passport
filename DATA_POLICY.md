# Data policy

Passport Switch is only useful if every fact can be checked. This policy is
short and strict.

## 1. Official sources only

Every rule must link to an official government source: an immigration
department, ministry of foreign affairs, embassy, or official e-visa / ETA
portal for the destination country.

Not acceptable as a source: blogs, travel aggregators, Wikipedia, social
media, visa agency sites, or AI summaries. Those may help you *find* the
official page, but the rule must cite the official page itself, and the
official page must actually say what the rule says.

## 2. Dated verification

Every rule carries a `verified` date (YYYY-MM-DD): the date a human checked
the official source. Do not copy a date forward. If you re-check a rule,
update the date. If the official page has changed, update the rule to match
it.

## 3. No guessing

If a rule cannot be verified on an official page, omit it. An omitted
destination is honest; a guessed rule can strand a traveller. Record
unverified destinations in the pull request description so someone else can
pick them up.

Tourism / short visit only. Work, study, and long-stay rules are out of
scope. Ordinary passports only, unless a rule explicitly says otherwise.

## 4. What to capture

For each rule, capture: status, duration, fee (if the official page states
one), conditions (passport validity, onward ticket, arrival cards, and so
on), extension rights if stated, and any caveat the official page warns
about. Quote or closely paraphrase the official page; do not embellish.

## 5. Scope (v1)

Passports: Vietnam (VN), Indonesia (ID), Philippines (PH), Thailand (TH).
Destinations: the ASEAN 10 plus Japan and South Korea. No
passport-to-itself entries. Nepal is explicitly out of scope for this
project; see the README for why the inspiration site already covers it.

## 6. Disclaimer

Informational only. Visa rules change without notice. Always confirm with
the official source linked on each card, and with your airline, before
you travel.
